# DocQA v0.3.5

## 更新内容

- 优化 PDF、DOC/DOCX 图文、表格与代码截图的解析、切块和索引稳定性。
- 优化问答检索：统一识别文件位置、表格操作和知识问答意图；补全跨块长答案并规范引用显示。
- 新增文件路径查询的模糊匹配，可根据不完整文件名、扩展名或语义相近名称定位已授权且已索引资料。
- 优化解析与问答并发调度，问答优先，并改善 SQLite 锁、遗留 Worker 与启动恢复处理。
- 优化应用内更新提示，展示新版本更新内容并保留完整 SHA-256 校验。
- 修复若干 PDF 混合图文、Unicode 编码和上下文预览问题。

## 说明

本 Release 不包含本地知识库、已生成向量、数据库、授权目录文件或测试资料。首次运行会使用当前安装目录外的 `user-data` 保存用户数据。
